# Estados de triagem

As skills falam em cinco papéis de triagem. Esta tabela liga cada papel ao nome usado na linha `Status:` dos
tickets deste repositório (em português, como os tickets existentes).

| Papel nas skills mattpocock | Nome aqui            | Significado                                   |
| --------------------------- | -------------------- | --------------------------------------------- |
| `needs-triage`              | `a-triar`            | O dono precisa avaliar                        |
| `needs-info`                | `falta-informacao`   | Esperando informação de quem abriu            |
| `ready-for-agent`           | `pronto-para-agente` | Especificado por inteiro, um agente faz sozinho |
| `ready-for-human`           | `pronto-para-humano` | Precisa de decisão ou ação do dono            |
| `wontfix`                   | `nao-fazer`          | Não vai ser feito (motivo registrado)         |

Ticket concluído: `Status: resolvido`.

Quando uma skill mencionar um papel (ex.: "aplicar o estado pronto para agente"), use o nome da segunda coluna.
